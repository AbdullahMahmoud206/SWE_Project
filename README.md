# Smart Environment Station SWE project:
**Smart Environment Station is an IoT-based system designed to monitor environmental conditions in real time. An ESP32 device collects data from different sensors such as temperature, humidity, and light intensity, then sends the measurements through Wi-Fi to a backend server. A mobile application allows users to monitor real-time readings, view historical data through charts, manage their devices, and receive alerts when specific environmental values exceed predefined thresholds.**

> **Project status:** In development.
